# Documentation

The index of the documents in this folder.

`aa-blinov` is a profile page: `README.md` is the product, and GitHub
renders it on the owner's profile. The documents here say what the page is
for, how it is put together, and which rules a change to it has to respect.

| Document | What it covers |
| --- | --- |
| [architecture.md](architecture.md) | How the page and the standard's tree fit together, and the decisions behind them. |
| [screenshots/README.md](screenshots/README.md) | Why the repository carries no images. |
| [../README.md](../README.md) | The front door, and the profile page itself. |
| [../PRODUCT.md](../PRODUCT.md) | Who the page is for, and what it must not turn into. |
| [../AGENTS.md](../AGENTS.md) | The commands, the layout of the tree, and the traps. |
| [../DESIGN.md](../DESIGN.md) | The visual record, and the statement that the page owns no style of its own. |

## Reading order

New here: [../README.md](../README.md), then [../PRODUCT.md](../PRODUCT.md)
for what the page is for and who reads it.

Changing the page: [architecture.md](architecture.md), then
[../AGENTS.md](../AGENTS.md) for the traps. The traps are the parts of this
repository that a reader cannot infer from the files.

Working on the standard itself: the checker lives in
[aa-blinov/golden-repo](https://github.com/aa-blinov/golden-repo), and
`AGENTS.md` shows the command.
